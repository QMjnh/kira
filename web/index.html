One-time setup

Scan with the iPad camera, or open and enter .

Shortcut 1: "Send to Kira" (edits back from Lightroom)
  1. Shortcuts app → + → name it Send to Kira. In its settings, turn on Show in Share Sheet and accept Images and Files.
  2. Add Repeat with Each over Shortcut Input.
  3. Inside it, add Get Contents of URL: URL = the address below followed by the Name of Repeated Item; Method POST; Request Body File = Repeated Item.
  4. After the loop, add Show Notification "Sent to Kira".

In Lightroom: select the edited photos → Share → Share to… → set size to Full size once → Send to Kira.

Shortcut 2: "Get from Kira" (photos to edit)
  1. New shortcut Get from Kira. Add Get Contents of URL with the address below.
  2. Add Split Text by New Lines, then Repeat with Each item.
  3. Inside: Get Contents of URL (Repeat Item), then Import to Lightroom. If that action is missing or fails on your iOS, use Save File to a "Kira" folder instead and import it in Lightroom with Add Photos → From Files.
  4. Optional: Automation → When Lightroom is opened → run Get from Kira.

No Shortcuts? Open Kira in Safari on the iPad and use the buttons on this page instead.

Cloud

Google Drive keeps exact copies of camera files, edits and project files. Google Photos keeps your phone photos and shows your Finals.

Google account

Google Drive backup

Drive never loses a file because of Kira: changed files are added as new copies, and files deleted on the library drive stay on Drive.

Google Photos

Checking and clean-up use Google Photos' web session (unofficial). If it ever stops working, nothing is lost; uploads keep using the official API.

Clean up Google Photos

Hides copies that duplicate a Final, such as other edits and phone originals you edited. They move to Archive: out of the timeline, still in your account, never deleted. Nothing happens until you click Hide.

    Nothing is overwritten. Each edit that comes back becomes the next version; the Final is the one shown in Google Photos.
